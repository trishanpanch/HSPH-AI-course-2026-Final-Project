## Preparation

Read the [facilitator guide](FACILITATOR_GUIDE.md), then the [original build-pack introduction](source-pack/README.md). Use your usual coding environment and model. Confirm your tools run and your group can use GitHub.

## The three sessions

1. **Define:** agree the PRD, create a GitHub repository and Project, and write the feature Issues.
2. **Build:** work through the first sprint's Issues to create one complete user journey.
3. **Finish and share:** complete the second sprint, test the prototype and prepare the pitch deck and class demo.
