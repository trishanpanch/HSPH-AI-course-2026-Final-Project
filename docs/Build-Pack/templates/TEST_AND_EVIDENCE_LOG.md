# Test and evidence log

Use fictional examples. Test the actual prototype against the PRD and record what happened. Link each result to the relevant GitHub Issue.

| Feature / Issue | Example used | Expected result | Observed result | Pass / fail | Fix or follow-up |
|---|---|---|---|---|---|
| | | | | | |

## What the results support

- What can we now demonstrate?
- What failed or remains uncertain?
- What is simulated?
- What should we test next?

For evaluation using an answer key, keep it separate from the build inputs. Report development cases and previously unseen test cases separately. After changing the product, record the retest rather than replacing the earlier failure.
